## Publicarla con GitHub Pages
Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.

## Actualizar

- **Textos:** en `index.html`; las traducciones al inglés están en el objeto `EN` del script final.
- **Certificaciones:** lista `CERTS` del script final, con su enlace de verificación de Coursera.
